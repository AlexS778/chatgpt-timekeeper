# ChatGPT Timekeeper v0.1.0-preview.1

First open-source development preview, prepared on 2026-10-10. Extension version: **0.1.0**. MIT licensed. Independent project; no OpenAI affiliation or endorsement.

## Included

- Browser-local date/time, UTC offset and zone prefix for supported outgoing ChatGPT text drafts.
- One persisted on/off toggle, live tab updates and a popup clock preview.
- Anchored prefix refresh on explicit retry; original text preservation and one Send-button continuation, with no automatic submission retries.
- Shared Chromium/Firefox source, unsigned local testing packages, pinned development dependencies, source/fixture tests and CI.
- Focused Send-button Space/Enter continuation fix, with dated installed-extension evidence in the feasibility record.

## Evidence and limits

The existing evidence records installed Firefox 157.0.1 and Chrome 153.0.8010.36 on macOS 27.0.1, including pointer Send, composer Enter, Unicode/code paste, Shift+Enter, toggles and navigation within the recorded scope. The focused-button fix was checked in both installed browsers. Controlled fixtures cover exact model text, selection/undo, failures/retries, pending gestures and changed-draft cancellation. See [the full dated record](../FEASIBILITY.md), including earlier failed checks and their fixes. Local preview-preparation verification is recorded in [the publication review](../PUBLICATION_REVIEW.md).

**This is not production-ready.** The full real-site acceptance gate remains incomplete. IME, attachment-only, long-draft and failure/undo matrix checks remain pending; fixture passes do not replace those checks.

**Send during active dictation is unsupported:** Firefox was reported to send an unstamped message. Stop dictation, wait for the transcript to enter the ordinary composer, then Send. No active-dictation implementation work is included in this release preparation.

Unknown rich editor layouts, ambiguous composers, unavailable settings and unsupported/localized Send controls may send unstamped. The integration depends on changing ChatGPT DOM controls and deprecated native editing APIs. A draft changed before continuation is retained for review; a native change that cannot be undone is a release-blocking failure, not successful stamping. Edge/Brave/Opera are untested; Safari, mobile and native apps are outside the preview. The browser/device clock is the time source.

The extension makes no network requests and stores only `enabled` locally. The inserted timestamp is visible and travels to ChatGPT with the normal message.

## Assets and installation

- `chatgpt-timekeeper-v0.1.0-preview.1-chromium.zip`
- `chatgpt-timekeeper-v0.1.0-preview.1-firefox.zip`
- `SHA256SUMS`

Verify checksums, extract the matching ZIP into its own directory, then follow [README installation instructions](../../README.md). Firefox is a temporary, unsigned add-on removed on browser restart. Chromium is loaded unpacked in Developer mode. There is no signed XPI or browser-store release, and the Firefox extension ID is provisional.

GitHub publication must mark this release **prerelease** and use these notes. Hosted CI results will only be available after the source is pushed; local validation must not be described as a completed GitHub Actions run.
