# ChatGPT Timekeeper v0.1.2-preview.1

Desktop development preview, released 2026-10-14. Extension version: **0.1.2**. This release provides a ready-to-load Chrome ZIP; users do not need Node.js, npm or a build step.

## Changes since 0.1.0

- Shorter, readable timestamps: `[Local time: 2026-10-14 19:10:26 GMT+3]`. The time-zone name stays in the popup. Both the new and older prefixes are recognized when refreshing a timestamp.
- Original clock icons, popup version and source/support/privacy links, and an offline privacy policy.
- Explicit extension-page security restrictions and updated Firefox transmission disclosures.
- Permanent Firefox ID and desktop-only Firefox packaging. Firefox 0.1.2 is also publicly available as an experimental add-on on [Mozilla Add-ons](https://addons.mozilla.org/en-US/firefox/addon/chatgpt-timekeeper/).
- GitHub Actions publishes the browser ZIPs and SHA-256 checksums after unit checks, browser fixtures, package validation, Mozilla lint and reproducibility checks pass.

The sending mechanism is unchanged from the earlier preview. This is an independent MIT-licensed project, without OpenAI affiliation or endorsement.

## Install in Chrome

1. Download **chatgpt-timekeeper-v0.1.2-preview.1-chromium.zip** from this release's assets and extract it into a folder you will keep.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the extracted folder containing `manifest.json`.
4. Reload your ChatGPT tab and send a message as usual.

Download the browser ZIP, rather than GitHub's Source code archives. Keep the extracted folder. Updates are manual: replace its contents with a later release, reload the extension, then reload ChatGPT. See the [README](https://github.com/AlexS778/chatgpt-timekeeper#install-in-chrome).

For Firefox, use the Mozilla listing for permanent installation. The Firefox ZIP in these assets is an unsigned development package, loaded temporarily through `about:debugging` and removed on restart.

## Evidence and limitations

The release workflow gates publication on hosted CI. Dated installed-browser evidence and its scope are recorded in [FEASIBILITY.md](https://github.com/AlexS778/chatgpt-timekeeper/blob/main/docs/FEASIBILITY.md) and [the Firefox submission record](https://github.com/AlexS778/chatgpt-timekeeper/blob/main/docs/FIREFOX_SUBMISSION.md). Fixtures use controlled editors and invented prompts; they do not establish complete live-site compatibility.

- Stop active dictation before sending; sending during recording can omit the timestamp.
- Formatted/code-block messages have a reported missing-timestamp issue under investigation. Unknown rich editor layouts and unsupported Send controls may send unstamped; check the visible message after sending.
- Live-site IME, failure/retry and undo acceptance remain incomplete. ChatGPT interface changes and deprecated native editing can affect compatibility.
- Safari, mobile browsers and native apps are unsupported. Other Chromium browsers and Firefox's declared minimum version are unvalidated.

The extension saves only its on/off preference, makes no network requests, and keeps no chat history. The visible timestamp is sent to ChatGPT with the user's message. This release does not complete the production acceptance matrix or signed Firefox installation-consent check.
