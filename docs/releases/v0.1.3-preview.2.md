# ChatGPT Timekeeper v0.1.3-preview.2

Preview notes prepared 2026-10-14. Extension version **0.1.3**.

- Fix missing timestamps on supported formatted messages: bold/italic text, links, headings, lists, inline code and code blocks.
- Put a new rich-message timestamp in a plain paragraph with a blank line before the original body. Preserve all original text and formatting.
- Refresh a separate existing timestamp on an explicit retry without stacking prefixes.
- Keep a draft for manual review if a failed edit cannot be undone; never continue an unverified send automatically.

Local validation: 21 unit/source checks, 88 Firefox/Chromium browser fixtures, package verification, Mozilla lint with zero errors/warnings/notices and reproducible ZIP builds. A temporarily installed Firefox 0.1.3 package sent the supplied rich example on real ChatGPT with unchanged body markup and a received timestamp. [Evidence and scope](https://github.com/AlexS778/chatgpt-timekeeper/blob/main/docs/FORMATTED_PASTE.md).

Chrome installation uses the Chromium ZIP: extract it, open `chrome://extensions`, enable Developer mode and choose **Load unpacked** for the extracted folder containing `manifest.json`. No user build tools are needed. Firefox ZIPs are unsigned temporary development packages; permanent installation uses Mozilla Add-ons after a new version is submitted and published.

This remains a desktop preview. Stop active dictation before sending. Unsupported editor structures may send unstamped, and broader real-site IME/failure/undo acceptance is incomplete. The extension retains the native editor's undo grouping, which can combine a recent paste and stamping. No new permissions, telemetry or developer collection.
